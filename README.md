# sdk-examples

Examples for BlueQubit Python SDK

## Examples

| Folder | Description |
|--------|-------------|
| `hierarchical_image_loading/` | Hierarchical / block image loading experiments |
| `notebooks/pps_snippet/` | Pauli-path simulator (PPS) code snippet notebook |
| `peaked_circuits/` | Peaked-circuit QASM examples |
| `t_gates_mitm/` | Meet-in-the-middle T-count package + tutorial notebook |

See each folder README (where present) for install and run instructions.
